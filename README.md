This C program implements a stack using a queue.
Functions:
push() - Adds an element to the stack and rotates elements to maintain stack order.
pop() - Removes and prints the top element.
peek() - Displays the top element.
is_empty() - Checks if the stack is empty.
stack_size() - Computes the current stack size.
main() - Provides a menu-based interface to perform stack operations.

Time and space complexity :
Push: Time complexity is O(n) and space complexity is O(1).
Pop : Time complexity is O(1) and space complexity is O(1).
Peek: Time complexity is O(1) and space complexity is O(1).
Is Empty: Time complexity is O(1) and space complexity is O(1).
Size: Time complexity is O(1) and space complexity is O(1).
