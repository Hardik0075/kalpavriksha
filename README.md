This C program implements a stack using an array and provides basic stack operations through a menu-driven approach. 1. push_in_stack() :-
a.Adds an element to the stack.
b.Checks for stack overflow before insertion.
c.Uses pointer top to update the position of the top element. 2. pop_from_stack() :-
a.Removes the top element from the stack.
b.Checks for stack underflow before removing. 3. peek_of_stack() :-
a.Displays the top element of the stack.
b.If the stack is empty, it prints a message.
4.check_if_stack_is_empty() :-
a.Checks if the stack is empty.
5.size_of_stack() :-
a.Displays the number of elements in the stack. 6. main()
a.Initializes the stack and its size limit.
b.Uses a menu-driven loop to perform different stack operations.

Time and Space Complexity :- 1. Push = Time Complexity : O(1) and spcae complexity : O(1) . 2. Pop = Time Complexity : O(1) and spcae complexity : O(1) . 3. Peek = Time Complexity : O(1) and spcae complexity : O(1) . 4. IsEmpty = Time Complexity : O(1) and spcae complexity : O(1) . 5. Size = Time Complexity : O(1) and spcae complexity : O(1) . 6. Main = Time Complexity : O(m), m is number of operation and spcae complexity : O(N) , where n is size of stack.
